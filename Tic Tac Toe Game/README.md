# Tic Tac Toe Game

A browser-based Tic Tac Toe game built using HTML, CSS, and JavaScript.
The project demonstrates core front-end development skills including DOM manipulation, event handling, and basic game logic implementation.

---

## Overview

This application provides two gameplay modes:

* Player vs Player
* Player vs Computer (basic AI)

Play against another player or challenge the computer with a basic AI that makes random moves.
It is designed with a clean UI and interactive feedback, making it suitable as a beginner-to-intermediate level front-end project.

---

## Key Features

* Classic 3x3 tic tac toe grid
* Dual game modes (PvP and PvC)
* Dynamic game state management
* Win and draw detection logic
* Visual feedback for winning combinations
* Restart button to reset the board
* Back-to-menu option to switch between modes
* Delayed AI move simulation for better user experience

---

## Tech Stack

* HTML5 – Structure and layout
* CSS3 – Styling and grid layout
* JavaScript (Vanilla) – Game logic and interactivity

---


## Application Flow

1. User selects a game mode from the main menu.
2. Game board initializes with empty state.
3. Players take turns placing marks (X or O).
4. After each move:

   * The system checks for a winning condition.
   * If no winner, the game continues.
5. In PvC mode:

   * The computer selects a random available cell after a short delay.
6. Game ends when:

   * A player wins, or
   * All cells are filled (draw).
